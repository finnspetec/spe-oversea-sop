Standard Operating Procedure

海外再生能源
專案管理 SOP

從第一次接到消息，到商業運轉後維運管理的完整標準作業程序。不管誰來接手，都能照著走。

版本v2.0
發布日期2026 年 5 月
主責部門海外課
適用地區越南・泰國・日本
機密等級🔒 內部機密
S1 商機評估 → S2 開發規劃 → S3 合約簽署 → S4 工程執行 → S5 維運管理
📌
本文件目的
建立標準化海外再生能源專案管理機制，確保所有案件在整個生命週期中均有明確的流程、產出、責任人與交接標準，解決「沒人知道案件在哪一步」、「交接靠記憶」、「每次都要重新想」、「歷程記錄分散」四大痛點。
📊
案件分類

案件分級表

所有海外案件進入 Stage 1 後，依以下分級決定需要走哪些 Stage。

L1-A
SPE 投資型
SPE 自行出資、建置、持有資產，透過 DPPA（直接購電協議）長期收取電費。
S1 S3 S4 S5
L1-B
EPC（工程採購施工合約）承攬型
業主自行出資，SPE 純施工交屋，資產歸業主所有。S5 視業主是否另外委託而定。
S1 S3 S4 S5*
L2
開發型
地面型開發、FIT（躉購電價制度）收購或 BESS（電池儲能系統）工業區案件，需複雜開發流程。
S1 S2 S3 S4 S5
L3
收購型
涉及股權交易、DD（盡職調查）完整執行、SPV（特殊目的公司）結構設計的收購或平台型案件。
S1 S2+DD S3 S4 S5
⚠️
S2 開發規劃僅適用 L2 / L3 案件。L1-A 及 L1-B 於 Stage 1 投審通過後，直接進入 Stage 3。
🔍
Stage 1

商機評估

從第一次接到消息 → 老闆核准投審。適用所有案件等級。

📊 泳道流程圖｜Stage 1 跨部門分工
📦 強制產出
📄 初評報告（Word） 📊 IRR（內部報酬率）試算 Excel 📋 投審 Check List ✅ 老闆核准紀錄
ℹ️
Check List 跨部門會簽僅適用 L2 / L3，L1-A / L1-B 不需要。
🚀 Gate 條件（全部達標才能進下一 Stage）
IRR（內部報酬率）≥ 12% DSCR（債務償還覆蓋率）≥ 1.1x PR（系統效能比）≥ 80% PPA（購電協議）意願 ≥ 15 年 業主信用非 C 級 老闆核准
結案機制
狀況處理後續
❌ 明確 Decline記錄原因 → 正式結案歸檔
⏸️ 條件不足打入 C 級候補池每季複查
📋
Stage 2

開發規劃

投審通過 → LOI（意向書）/ MOU（備忘錄）簽署。僅適用 L2 / L3 案件。

⚠️
LOI（意向書）/ MOU（備忘錄）彈性簽署原則：若業主要求獨家期（Exclusivity），應於 Stage 1 投審通過後立即啟動，最晚於本 Stage 結束前完成。
📊 直向流程圖｜Stage 2 含 LOI 彈性分支
📦 強制產出
⚖️ LDD（法律盡職調查）初步報告 📊 FDD（財務盡職調查）初步報告 🏦 融資洽詢備忘錄 📝 LOI（意向書）/ MOU（備忘錄）正式簽署
🚀 Gate 條件
LDD（法律盡職調查）無重大法律瑕疵 土地年限對齊 PPA（購電協議）年期 融資可行性初步確認 LOI（意向書）/ MOU（備忘錄）簽署完成
⚖️
Stage 3

合約簽署

LOI（意向書）→ EPC（工程採購施工合約）合約簽署完成，準備動工。適用所有案件等級。

📊 橫向流程圖｜依案件等級的三條合約路徑
📦 強制產出
📄 PPA（購電協議）正式合約 🏠 屋頂 / 土地租約 🏗️ EPC（工程採購施工）合約 🤝 SPA（股份買賣協議）/ SHA（股東協議）（L3） 🏦 銀行 Term Sheet（融資條件書） 🔎 DD（盡職調查）完整報告（L2/L3）
🚀 Gate 條件
所有合約簽署完成 DD（盡職調查）無重大瑕疵 融資 Term Sheet 確認 老闆最終核准動工
🏗️
Stage 4

工程執行

動工 → COD（商業運轉日）完成。海外課專案負責人主導，工程技術部駐點監工。

📊 雙線並行圖｜工程線 & 行政許可線同步推進
📦 強制產出
📅 工程甘特圖（三方確認） 💳 PCM（資金控管機制）付款紀錄 📊 包商施工進度週報 📓 工程技術部監工日誌 ✅ 設備驗收報告 🚒 消防許可證 🔌 併網同意書 🎯 COD（商業運轉日）三方簽署文件 📐 竣工圖
🚀 Gate 條件
所有許可證齊備 設備驗收通過 PR（系統效能比）達標 併聯完成 COD（商業運轉日）三方確認
⚙️
Stage 5

維運管理

COD（商業運轉日）→ PPA（購電協議）合約期滿。適用所有等級。

📊 監控異常處理分支圖｜Stage 5-A
5-B 定期巡檢與清洗
模式頻率
🔷 密集型每季一次，共 4 次／年（巡檢 + 清洗）
🔹 標準型每半年一次，共 2 次／年（巡檢 + 清洗）
5-C 電費收款
💰
海外課製作月度請款文件 → 業主確認 → 電匯至指定帳戶 → 通知財會部對帳
5-D 業主報告
類型頻率內容
月報每月發電量、PR（系統效能比）、收益
年報每年全年績效、O&M（營運及維護）摘要、下年度計畫
5-E 合約管理
時間點動作
O&M 到期前 6 個月啟動續約或重新競標
PPA 到期前 12 個月啟動續約談判或設備移轉討論

治理機制 B
Stage 交接包
✅
每個 Stage 結束時強制填寫。未填寫交接包不得進入下一 Stage。確保任何人接手都能快速上手，不靠記憶。
欄位說明
📦 本 Stage 完成的產出清單所有文件名稱與檔案路徑
⏸️ 未竟事項還沒做完的、還在等待的事項
⚠️ 注意事項踩過的坑、需要特別留意的
▶️ 下一個 Stage 第一步行動具體到「誰在什麼時間做什麼事」
📅 交接日期實際交接完成日期
👤 交接人填寫交接人姓名
治理機制 C
變更控制
⚠️
以下任何情況發生，必須立即填寫變更記錄，不得依賴記憶。
🔄 觸發條件
裝置容量調整 電價或 PPA（購電協議）條件重談 業主或關係人變更 時程延誤超過 2 週 預算變動超過 10%
記錄欄位說明
📅 變更日期發生變更的日期
📝 變更內容改了什麼（具體描述前後差異）
❓ 變更原因為什麼要改
📊 影響評估對 IRR（內部報酬率）、時程、合約的影響
✅ 核准人老闆或海外課專案負責人
